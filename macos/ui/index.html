Frame 本地媒体工具箱

选择工具，预览素材，调节输出质量后导出。

  1. 添加文件

    从左侧选择工具，再添加文件。也可以直接拖入 MP3、MP4、PAG 或 SVGA，自动分配到合适的工具。

  2. 预览与检查

    动画支持时间轴预览；音视频可用原生播放器预览。MP3 可对比试听原音频和处理结果，GIF 可选择尺寸、帧率和背景。

  3. 转换并交付

    拖动质量滑块或点选推荐档位。完成后仍可调整设置并重新导出，每次生成新文件。PNG 序列保持无损，独立设置尺寸与帧率。

添加文件 ⌘ O开始转换 ⌘ ↵播放 / 暂停 Space上一帧 / 下一帧 ← →

支持 macOS 13+，无需 Node.js、Chrome 或联网。SVGA 最大 64 MB，PAG 最大 256 MB，音视频最大 2 GB。GIF 无音频且仅支持 256 色。推荐 MP3 模式不保证每个源文件都有压缩空间。
