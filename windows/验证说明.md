# 验证范围

已测试共享桌面主程序的真实 IPC、源动画预览、SVGA→PAG、SVGA→GIF、PAG→GIF、MP3 压缩、MP4→PNG、重新导出和取消。测试在 macOS 的 Electron 45.1.0 宿主进行，媒体组件为该机器 FFmpeg 8.1。最终 ASAR 包也通过真实转换测试。

新增 PAG 编码器通过独立 libpag 实际解码比对，保留 750×750、20 fps、100 帧、5 秒。抽查五帧的白底平均绝对误差约 2.47/255，透明度误差约 0.91/255；另外检查了 17×19 奇数尺寸、完全透明帧及反向跳帧。GIF 产物检查了 320×320、25 帧与非空画面；PNG 测试输出 10 帧。

Windows Frame.exe、FFmpeg.exe、FFprobe.exe 与 codec DLL 的 PE 架构为 AMD64（0x8664），依赖检查没有缺失的随包 codec DLL。官方运行时压缩包按发布方 SHA-256 核验。Frame 图标和版本资源已写入 PE。安装器为可安装到当前用户的 NSIS 程序。
